# Notebook collections 

This directory contains Jupyter notebooks used for data preprocessing and downstream analyses.

## Directories 

* `alpha_diversity`: Alpha diversity analyses
* `disease_associated_microbes`: Analysis of associations between microbial abundance and disease status
* `enterotype`: t-SNE based dimensionality reduction and clustering analyses
* `machine_learning`: Machine learning analyses for predicting disease status
* `microbial_interaction_network`: Network-based analyses of microbial associations
* `preprocess`: Data preprocessing workflows
* `survival_analysis`: Survival analyses for treatment step-up
