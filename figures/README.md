# Figure collections 

This directory contains visual representations of the analysis results.

## Directories 

* `alpha_diversity`: Alpha diversity plots 
* `enterotype`: Two-dimensional visualization of t-SNE embeddings and enterotype clusters 
* `group_comparison`: Disease group-sepcific and enterotype-specific microbial abundance plots
* `machine_learning`: Feature importance and Shapley value plots 
* `microbial_interaction_network`: Network visualization using Cytoscape 
* `survival_analysis`: Kaplan-Meier survival plots
