# Result data files  

This directory contains the output files generated from downstream analyses.

## Directories

* `enterotype`: Enterotype identification using t-SNE–based dimensionality reduction and clusteringg 
* `fastspar`: Microbial interaction network analysis performed using FastSpar
* `group_comparison`: Group-wise comparisons of microbial relative abundance profiles 
* `machine_learing`: Machine learning models for disease status classification 
* `microbial_interaction_network`: Results of microbial interaction network analyses
