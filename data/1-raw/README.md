# Raw data files 

## FASTQ files 

The 16S rRNA amplicon sequencing data targeting the V3–V4 region are publicly available in the European Nucleotide Archive (ENA) and NCBI Sequence Read Archive (SRA).

The dataset is deposited in ENA under the project accession PRJEB101301.

## Metadata

* `group.tsv`: Sample group information, including disease status.
* `medication_step_up.xlsx`: Medication step up data.
* `metadata.tsv`: Sample metadata including age, sex, BMI (body mass index), CRP (C-reactive protein)
* `sample_run_accession.tsv`: Run accession index for each sample
